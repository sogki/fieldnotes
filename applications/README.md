<h1 style="text-align:center">🔎 Application investigations</h1>

<a href="../README.md" style="color:#c77dff"><img src="../assets/branding/fieldnotes-arrow-back.svg" width="14" height="14" alt=""> Fieldnotes</a>

Application profiles document how specific software behaves on a system: distribution, installation, persistence, networking, privacy claims, and open questions.

Profiles are research notes—not completed security audits—unless a document explicitly says otherwise.
